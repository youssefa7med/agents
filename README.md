# AI Financial & Web Search Assistant

![AI Financial Assistant](https://cdn.dribbble.com/users/2206859/screenshots/5795316/main_robot_dribble_icon_1.gif)

## 📌 Overview

The **AI Financial & Web Search Assistant** is a powerful chatbot designed to provide financial insights, stock market analysis, and relevant company data. It also performs web searches to retrieve up-to-date financial news.

🔗 **Try the project here:** [AI Financial Assistant](https://agents-ai.streamlit.app)

---

## ⚡ Features

- 📊 **Financial Data Analysis**: Get stock prices, company fundamentals, and market trends.
- 🔍 **Web Search**: Fetch real-time financial news and company information.
- 📑 **Structured Responses**: Uses tables and markdown for clarity.
- 🤖 **Conversational Interface**: Interactive chat-based experience.

---

## 🛠️ Technologies Used

- **Streamlit**: For the web-based UI.
- **Phi Agents**: AI agent framework.
- **Groq (DeepSeek R1 Distill LLaMA 70B)**: AI model for financial analysis.
- **YFinanceTools**: For stock market data.
- **DuckDuckGo API**: For web search capabilities.
- **Python**: Core programming language.

---

## 🚀 How to Use

1. Open the chatbot using the [project link](https://agents-ai.streamlit.app).
2. Enter a financial-related question in the chatbox.
3. The AI will analyze and return detailed financial insights or web search results.
4. Use the sidebar to clear chat history if needed.
5. Every response ends with **"Do you want any more help? 😊"** to keep interactions engaging.

---

## 📜 Instructions for Developers

### 🔹 Installation

```bash
pip install streamlit phi-agent yfinance duckduckgo-search python-dotenv
```

### 🔹 Running the Project

```bash
streamlit run app.py
```
